# Paljun herra

Retrohenkinen suomalainen selainpeli: poreallas, mökki, Cessna, yökerho Falcon, taistelu ja Moottorijahti.

## Pelaa

- **Selaimessa (puhelin ja tietokone):** https://claude.ai/artifact/5G6NK3T25MGUbhniSuJ5hX
- **Windows 10/11, toimii ilman nettiä:** [Lataa PaljunHerra-Windows.zip](https://github.com/Esahvibeltaa/Paljun-herra/raw/main/lataa/PaljunHerra-Windows.zip)

### Windows-version käyttö

1. Pura zip esimerkiksi työpöydälle.
2. Kaksoisnapsauta `PaljunHerra-win_x64.exe`.
3. Jos Windows näyttää ilmoituksen "Windows suojasi tietokonettasi", valitse **Lisätietoja → Suorita silti** (ohjelmaa ei ole allekirjoitettu kaupallisella varmenteella).

Peli ei asenna mitään. Poistoon riittää kansion poistaminen. Tarvitsee Microsoft Edge WebView2:n, joka on valmiina Windows 11:ssä ja päivitetyissä Windows 10 -koneissa.
